# 기여 접수·검토·공개

[기여 웹사이트](https://standard.linh.day/) 또는 GitHub 이슈를 통해 제안할 수 있습니다. 웹 접수는 본문과 첨부파일을 비공개로 저장하고, 운영자가 공개 범위를 별도로 검토한 자료만 자료실에 올립니다. 검토 수용은 현업 채택이나 성과 검증을 뜻하지 않습니다.

웹 접수 후 발급되는 확인 파일을 안전하게 보관하면 접수 상태를 조회할 수 있습니다. 확인 키를 잃으면 익명 접수의 소유권을 자동으로 복구할 수 없으므로 공개하지 말고 따로 보관해 주세요. 같은 내용을 재시도하면 기존 접수를 확인합니다.

자료실의 공개 자료는 검색·열람하고 Markdown이나 공개된 첨부로 내려받을 수 있습니다. 초기 자료와 합성 예시는 현업 검증 전이며, 사용자는 출처·라이선스·적용 범위를 확인해야 합니다. 실제 회의 원문, 고객 정보, 인증정보와 평가 전 보류 사례는 제출하지 마세요.

웹사이트와 앱의 구현·운영 코드는 별도 비공개 저장소에서 관리합니다. 이 공개 저장소는 업무 문서, 양식, 평가 방법과 GitHub 기여 경로를 계속 제공합니다.
