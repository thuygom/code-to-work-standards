# 코드·계약 근거 카드

원본 코드를 공개 저장소에 복사하지 않고, 확인한 동작과 범위를 자신의 말로 정리해 주세요. 비공개 저장소·서비스의 URL, 내부 경로, 원본 로그와 고객 자료는 넣지 않습니다.

| 항목 | 작성 내용 |
|---|---|
| 근거 ID | 예: `CODE-N-001` |
| 확인일·확인자 역할 |  |
| 확인 방법 | 문서 읽기 / 정적 코드 읽기 / 모의 실행 / 실제 실행 |
| 소스 참조 | 공개가 허용된 참조 또는 `PRIVATE-CODE-001` 같은 비공개 식별자 |
| 소스 버전 | 공개 가능한 커밋·태그 또는 비공개 버전 식별자 |
| 관련 단계·요구 | 예: `N01`, `PRD-N-01` |
| 공개 검토 상태 | 미검토 / 가공 중 / 공개 승인 |

## 해석 경계

코드의 호출 순서가 현업의 SOP와 같다는 뜻은 아닙니다. 문서의 설명, 정적 구현, 실행 결과, 현업 수용을 구분합니다. 정적 읽기만 했다면 `검증 완료`, `운영 적용`, `성능 달성`으로 표시하지 않습니다.
