# PDF 원본

이 폴더에서 `xelatex -interaction=nonstopmode -halt-on-error main.tex`를 두 번 실행합니다. XeLaTeX와 fontspec, geometry, xcolor, array, longtable, enumitem, amsmath, tikz, titlesec, hyperref가 필요합니다. 글꼴은 fonts/에 동봉했으며 OFL.txt를 따릅니다.

출력은 main.pdf입니다. 검토 후 ../workflow-standards-v0.1.pdf에 반영합니다. 이 파일은 v0.1 시점의 문서이며 현업 검증 완료본이 아닙니다.
