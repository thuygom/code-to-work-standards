## 공개 가공

- 실제 회사·인물은 고객사 A·제조사 B·담당자 A처럼 일반화했습니다.
- 실제 고객 원문·계정·연락처·운영 주소·자격증명·원본 로그·제품 내부 저장 경로는 옮기지 않았습니다.
- 설명 사례는 합성·미실행으로 표시했습니다. 소스 계약의 존재와 현업 검증 상태를 구분합니다.
- 출처 프로젝트명, 공식 방법론의 기관명, 외부 권리자·라이선스 표시는 유지합니다.

## 외부 근거

EPA QA/G-6, GOV.UK 경험 지도 지침, NASA 요구사항 작성 지침을 Firecrawl로 확인했습니다. 자체 적용 양식과 짧은 요약만 제공하며 원문 PDF·이미지는 재배포하지 않습니다. 외부 원문의 라이선스가 Standard의 MIT로 바뀌지 않습니다. 각 자료의 원문 링크와 권리 표시를 유지하세요.

## DB 반영

`catalog.json`의 고정 요청 키와 내용 해시를 사용합니다. 같은 초기 자료를 다시 넣어도 중복 생성·중복 공개하지 않습니다. 이미 적용한 내용을 같은 키로 바꾸면 실패합니다. 내용을 개정할 때는 새 키로 새 기여를 만들고 이전 자료의 공개 상태를 명시적으로 정리합니다.

```bash
node --env-file=local-deploy/database.env scripts/seed_library.mjs --publish-reviewed
```

이 명령은 초기 자료의 공개 가공·출처 검토를 마친 운영자가 사용합니다. 일반 접수는 자동 공개되지 않습니다.
