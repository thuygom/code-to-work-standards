# SOP 시작 양식 — 다른 사람이 따라 할 수 있는 절차

## 참고 원칙

US EPA의 QA/G-6는 업무를 아는 사람이 절차를 작성하고, 다른 사람이 재현·검토하며, 개정과 문서 버전을 관리하도록 안내합니다. 체크리스트는 절차의 일부로 다룹니다. 환경 업무용 지침에서 일반 작성 원칙만 참고했습니다.

## 이 프로젝트의 작성 양식

- 절차 ID / 제목 / 버전 / 작성·검토일:
- 목적 / 적용 업무 / 제외 범위:
- 수행자와 필요한 경험·권한:
- 시작 조건 / 입력 자료 / 사용하는 도구:
- 단계별 행동 / 판단 / 전달물:
- 정상·경계·실패 상황과 재개 위치:
- 완료 조건 / 남길 증거:
- 검토자 / 변경 이유 / 다음 검토 조건:

## 합성 적용 예시

자료 검토 업무라면 “파일 열기” 뒤에 무엇을 확인해야 하는지 적습니다. 파일이 없을 때의 보완 요청, 잘못된 버전을 받았을 때의 중지, 검토 완료를 알리는 전달물도 남깁니다. 체크박스만 채웠다고 정확한 업무 수행이 입증되는 것은 아닙니다.

## 출처와 이용 범위

[US EPA, Guidance for Preparing Standard Operating Procedures, QA/G-6, 2007](https://www.epa.gov/sites/default/files/2015-06/documents/g6-final.pdf), §§2.1–2.5. 2026-10-30 원문 확인. 짧은 요약과 새로 작성한 양식이며 원문 PDF·도표를 재배포하지 않습니다. 원문 권리는 발행처에 따릅니다. 이 자료는 기관의 인증·승인이나 특정 분야의 규제 충족을 의미하지 않습니다.
