# SYN-N-001 — 요청과 확정 상태를 구분하는 회의록 사례

**모든 내용이 가상인 합성 예시이며 실행·현업 검토 전입니다.** 실제 고객·직원·회의를 나타내지 않습니다. 아래 기대 결과는 양식과 판단 규칙을 설명하는 초안이며 실제 성과 집계에 넣지 않습니다.

| 항목 | 값 |
|---|---|
| 예시 ID | `SYN-N-001` |
| 사례 ID | `CASE-N-001` — 합성 예시용으로 사용합니다. |
| 원천·사용 구분 | 합성 / 예시 전용 |
| 출력 유형 | N2 팀 공유 회의록 |
| 기대 결과 상태 | 초안, 현업 승인 전 |
| 실행 상태 | 미실행 |

## 가상 요청과 원문

요청: 다음 대화에서 요청된 일, 확정된 일, 아직 정하지 않은 일을 구분해 회의록에 남겨 주세요. 달력 날짜로 변환할 기준시각은 제공하지 않았습니다.

| 원문 위치 | 가상 발화 |
|---|---|
| `SRC-SYN-N-001:L1` | 진행자: “자료 담당님, 금요일까지 제품 소개 초안을 준비해 주세요.” |
| `SRC-SYN-N-001:L2` | 자료 담당: “현재 일정을 확인한 뒤 가능 여부를 말씀드리겠습니다.” |
| `SRC-SYN-N-001:L3` | 진행자: “좋습니다. 초안 일정은 아직 확정하지 않고, 기초 자료는 제가 오늘 전달하겠습니다.” |

## 기대 사실과 상태

| 항목 | 기대 결과 | 근거 |
|---|---|---|
| 요청 | 진행자가 자료 담당에게 제품 소개 초안 준비를 요청했습니다. | L1 |
| 요청 기한 | 금요일은 명시된 **요청 기한**입니다. 구체적인 달력 날짜는 미확인입니다. | L1 및 기준시각 미제공 |
| 수락·확정 | 자료 담당은 가능 여부 확인을 약속했으며 초안 일정은 미확정입니다. | L2–L3 |
| 확정된 후속 행동 | 진행자는 기초 자료를 오늘 전달하겠다고 밝혔습니다. 실제 전달 완료 여부는 알 수 없습니다. | L3 |
| 다음 확인 | 자료 담당의 가능 여부와 초안의 확정 일정을 확인해야 합니다. | L2–L3 |

요청의 수행 대상과 요청 기한을 보존하면서 수락·확정 여부를 구분해야 합니다. 수락이 없다는 이유로 자료 담당과 금요일을 모두 삭제하는 결과도 적절하지 않습니다.

## 허용되는 결과 표현

> 제품 소개 초안 작성이 자료 담당에게 요청되었으며 요청 기한은 금요일입니다. 자료 담당은 일정 확인 후 가능 여부를 회신하기로 했고, 초안 일정은 미확정 상태입니다. 진행자는 기초 자료를 오늘 전달하기로 했습니다.

문구가 같을 필요는 없습니다. 역할·요청 기한·미확정 상태·후속 행동이 보존되는지 봅니다.

## 반려할 결과

- “자료 담당이 금요일까지 초안을 완성하기로 확정했습니다.”
- “담당자와 기한은 전혀 정해지지 않았습니다.”
- “진행자가 기초 자료 전달을 완료했습니다.”
- 제공되지 않은 기준일을 가정해 금요일과 오늘을 구체 날짜로 확정합니다.
